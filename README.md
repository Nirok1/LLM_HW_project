# Извлечение таблиц из SQL с помощью LLM для Data Lineage

## Модель
Дообученный адаптер LoRA (папка `phi3_mini_lineage`) доступен по ссылке: 
После скачивания распакуйте папку в корень проекта.
## Описание
Проект представляет собой MVP системы для автоматического извлечения имён таблиц-источников из SQL-кода с использованием дообученной языковой модели. Цель — облегчить построение Data Lineage.

## Структура
- `final_notebook.ipynb` – основной ноутбук с разметкой данных, обучением, оценкой и демо.
- `labeled_sourceres.jsonl/` – размеченные данные.
- `labeled_sourceres.jsonl/` – размеченные данные.
- `обучающие данные.jsonl/` – тестовые даннык.
- `test_small.jsonl/` – тестовые даннык.
- `phi3_mini_lineage/` – сохранённый адаптер LoRA (дообученная модель).
- `requirements.txt` – зависимости.

## Как воспроизвести
1. Установите зависимости: `pip install -r requirements.txt`
2. Откройте `final_notebook.ipynb` в Jupyter/Colab.
3. Последовательно выполните ячейки. Если нужно только оценить уже обученную модель, можно загрузить её из папки и запустить ячейки оценки.

## Выводы
Дообучение на 1000 примерах с помощью QLoRA улучшило F1 на 4% и повысило полноту на 4%, а также позволило модели возвращать имена таблиц со схемой. Система устойчива к простым атакам, но требует доработки фильтрации временных таблиц.
